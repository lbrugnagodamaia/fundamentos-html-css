# Fundamentos de HTML e CSS

Repositório criado para documentar minha jornada de estudos em desenvolvimento web.

Aqui estão os exercícios e práticas realizados durante minha formação, com foco em estruturação de páginas, estilização e criação de layouts responsivos.

## 📚 Conteúdos estudados

- HTML5
- CSS3
- Box Model
- Flexbox
- CSS Grid
- Pseudo-classes e pseudo-elementos
- Estruturação de páginas web
- Layouts responsivos

## 📂 Organização

Os exercícios estão organizados em pastas de acordo com as aulas do curso.

Cada pasta contém os arquivos desenvolvidos durante os estudos.

## 🎯 Objetivo

Desenvolver uma base sólida em HTML e CSS para avançar nos estudos de JavaScript e, posteriormente, React e TypeScript.
